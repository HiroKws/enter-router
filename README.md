# enter-router

**Enter キーの意味を、押し方で振り分ける常駐ツール（Windows 専用）。**

Enter 1 回＝改行／2 回＝送信／3 回＝AI（Hermes）へ／4 回以上＝取り消し。
チャット欄で「送信してしまう Enter」と「改行したい Enter」を、押し方で使い分けられます。

> **対応 OS は Windows 11（64bit）のみです。** macOS / Linux では動きません
> （Linux 側で動くのはテストだけです）。

---

## 🚨 まず最初に覚えてください — 止め方（パニック）

> # **F1 を 3 回連打すると、すぐ止まります。システムトレイのアイコン、右クリックからも止まります。**
>
> キーの横取りを即座に解除し、以後は普通のキーボードに戻ります。

| 止め方 | 操作 |
|---|---|
| **キーボード（これを覚えてください）** | **`F1` を 3 回連打**（ |
| マウス | タスクトレイのアイコンを**左クリック → 右上の「パニック停止」**（1 クリック） |
| 再開 | トレイを左クリック →「再開」 |

## できること

| 操作 | 意味 | 実際に起きること（例: チャット欄） |
|---|---|---|
| **Enter 1 回** | 改行 | 0.25 秒待ってから改行が入る（送信されない） |
| **Enter 2 回**（連続） | 送信 | 改行は入らず、送信キーを 1 回だけ送る |
| **Enter 3 回**（連続） | AI へ | 入力中の文章を Hermes に渡し、応答を通知で返す |
| **Enter 4 回以上** | 操作取り消し | **何もしない**（改行も送信もしない）。入力中の文章はそのまま残る |
| **Alt+F5** | アプリ登録 | アクティブウィンドウのプロセスを設定に追加 |
| **Alt+F6** | アプリ＋タイトル登録 | プロセス＋ウィンドウタイトルで登録、ブラウザ向け |

- 「連続」と判定する間隔は **0.25 秒**（実測: 連続入力 96〜201ms、非連続 495〜585ms）。
- 日本語入力の**変換中**（未確定文字列あり）の Enter は横取りしません＝確定はアプリ/IME に任せます。
  その確定 Enter は**連続打鍵として数えません**（確定してから改行・送信をしたいときは、確定後に Enter を押し直す）。
- **登録していない**アプリではキーを横取りしません。

## インストール

1. **Python 3.14（64bit）** を入れる（[python.org](https://www.python.org/downloads/windows/) の
   “Windows installer (64-bit)”。`tcl/tk` は既定で入ります）。
2. このリポジトリを好きなパスに置く（例: `C:\Tools\enter-router`）。
3. **動作確認（任意・フックを張らないので安全）**:

  インストール済みパスへワーキングディレクトリを移動後：

   ```bat
   python src\enter_router\main.py --once
   ```

   `warnings: 0` とトリガ→意味の一覧が出れば設定は正常です。

4. **常駐起動**（コンソールを出さない）:

  インストール済みパスへワーキングディレクトリを移動後：

   ```bat
   pythonw.exe src\enter_router\main.py
   ```

   タスクトレイにアイコンが出れば動いています（緑＝有効）。
   初回起動時に設定ファイル `%APPDATA%\enter-router\config.json` が自動で作られます。

5. **Windows 起動時に自動で立ち上げる**（任意）:
   `Win+R` → `shell:startup` → 開いたフォルダに
   `pythonw.exe src\enter_router\main.py` のショートカットを置く。

6. **終了**: トレイを左クリック →「終了」（設定は残ります）。

## 使い方

### 1. まずはアプリを登録する（いちばん大事）

登録していないアプリでは**何も起きません**。使いたいアプリのウィンドウを前面（アクティブ）にして:

- **`Alt+F5`** … そのアプリを丸ごと対象にする（例: メモ帳のどのウィンドウでも）
- **`Alt+F6`** … **いま開いているそのウィンドウだけ**を対象にする（タイトルまで一致、ブラウザ向け）

押すと「登録しました: <名前>」と通知が出て、設定ファイルに追記されます（再起動不要）。
同じものを二度押しても増えません。登録内容は設定画面のタブ B で後から編集できます。

### 2. 押し方で使い分ける（設定例）

- 改行したい → **Enter 1 回**（0.25 秒待ってから改行が入ります）
- 送信したい → **Enter 2 回**（速く）
- AI に聞きたい → **Enter 3 回**
- 押し間違えた → **Enter 4 回以上**（全部取り消し。文章は消えません）
- 他に機能キーによるコンビネーションにより設定できます。

### 3. 設定画面

トレイを左クリック（またはトレイメニューの「設定を開く」）。

| タブ | 内容 |
|---|---|
| 操作マップ | Enter 1/2/3 回などが何を意味するか、判定の窓（ms）、**パニックキーと連打回数**、登録キー |
| プロファイル | アプリごとの送信キー／改行キーの割り当て、追加・複製・削除、送り先（クリップボード／AI チャット／Hermes）の設定 |
| テスト送信 | 送り先に実際に 1 回送ってみる（成否と理由が画面に残ります） |

「保存」は検証してから書き込みます（不正な値なら**ファイルは変えず**、どの項目が悪いかを表示）。
「キャンセル」で変更を破棄。設定ファイルが外から変わった場合（登録キーなど）は自動で読み直します。

### 4. 設定ファイル

`%APPDATA%\enter-router\config.json`（JSON。直接編集しても、保存すれば自動で反映されます）。

初回起動時に作られる設定ファイルは **プロファイルが空**です（＝未登録なので全アプリ素通し。
登録キーでアプリを足すのがオプトイン）。`site-a` / `site-b` / `excel` のような**サンプルは
同梱の [`config/sample.config.json`](config/sample.config.json) と docs/design.md §4.2 にだけ
入っています** — 実運用の設定に混ざることも、作り直しで復活することもありません。

**どのアプリでも動かしたい**場合は、同梱の
[`config/chat-default.config.json`](config/chat-default.config.json) を
`%APPDATA%\enter-router\config.json` にコピーしてください（全アプリが対象になります）。
主な項目:

```json
{
  "policy": {
    "hold_window_ms": 250,         // 「連続」と判定する間隔（実測値）
    "triple_enter_window_ms": 250, // 2→3 発目、および 4 連打の取り消し判定
    "panic_key": "f1",             // 緊急停止キー（このキーの連打で停止）
    "panic_repeat": 3              // 何回で停止するか
  },
  "registration": {
    "process_key": "alt+f5",       // 前面アプリの登録（プロセスのみ）
    "process_title_key": "alt+f6"  // 前面アプリの登録（＋ウィンドウタイトル）
  }
}
```

## うまく動かないとき

| 症状 | 確認すること |
|---|---|
| 何も起きない | そのアプリを登録していますか（`Alt+F5`）。未登録アプリは素通しです |
| Enter 2 回が送信にならない | 2 回の間隔が 0.25 秒を超えていませんか（遅いと 2 回の改行になります） |
| 日本語入力でおかしくなる | 変換中（未確定）の Enter は対象外です。確定後の Enter で試してください |
| 日本語入力中に改行できない | 確定 Enter は数えない仕様です。確定後にもう一度 Enter を押すと改行、2 回で送信です |
| 変換が確定せず Enter が改行になる | IME の状態を読めないアプリでは、直前の Enter 以降に**文字を打ったか**で判定しています。文字を打たずに Enter した場合は改行になります（設定 `global.ime_unknown_policy` で挙動を変更可） |
| 特定のアプリだけ効かない | 管理者権限で動くアプリは OS の制限で対象外です |
| ブラウザで `Alt+F3`（タイトル登録）したのに効かない | Web アプリは**会話ごとにタイトルが変わります**（例: `新規チャット - Claude …` → `Greeting - Claude …`）。未マッチ＝素通しになり、ログに `resolved=pass` が残ります。`*Claude — Mozilla Firefox` のようなワイルドカードか、URL 照合（`"url": "*claude.ai*"`）を使ってください |
| 止め方がわからなくなった | **`F1` を 3 回連打**（それでもだめならトレイの「パニック停止」） |
| 原因を調べたい | ログ: `%APPDATA%\enter-router\logs\enter-router.log`（1 判定 1 行。打鍵内容は記録しません） |

### 書き直しのすすめ（別言語の環境があるなら）

Rust / C++ / Go / Zig など、低レベル操作と速度に強い言語の開発環境が整っているなら、お使いのエージェントに書き直してもらうことをおすすめします。

理由:

- グローバルキーフックのコールバックは **1 打鍵あたり数百マイクロ秒**の予算しかなく、OS は
  遅いコールバックを黙って外します（本実装は予算監視と自動アンフックで耐えていますが、
  GC の無い言語ならこの種の防御をかなり減らせます）。
- 単一バイナリで配布でき、利用者に Python のインストールを求めずに済みます。
- 低レベル API（フック・入力注入・クリップボード・COM/TSF）は Python では `ctypes` 頼みになり、
  構造体や型を手で定義する必要があります（このリポジトリにもその苦労が残っています）。

Python 版は「ビルド不要・そのまま読める」利点があるので、まず動かして仕様を固め、
その仕様をエージェントに渡して別言語へ移植する、という進め方が現実的です。
